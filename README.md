# Jeu de programmation pour enfants entre 8 à 12 ans.

##  Technologies utilisées

- **Python** : langage de programmation principal.
- **Emoji** : bibliothèque utilisée pour l'affichage des emojis dans le jeu.

## Installation

### 1. Cloner le projet

```bash
git clone <url soit ssh ou https>
```
```bash
cd Dev2Projet-2026-2027
```
### 2. Création de l'environnement de développement
```bash
python3 -m venv env
```

### 3. Activation de l'environnement de développement
#### 3.1 Windows
```bash
source env\Scripts\activate
```

#### 3.2 Linux/MacOs
```bash
source env/bin/activate
```

### 4. Installation des dépendances 'emoji'
#### 4.1 Aller dans le dossier docs contenant le fichier requierments.txt
```bash
cd docs
```
#### 4.2 Installer les dépendances
```bash
pip3 install -r requirements.txt
```
### 5. Lancer le projet
#### 5.1 Aller à la racine du projet
```bash
cd ..
```
#### 5.2 Lancement du projet
```bash
python3 src/main.py
```
